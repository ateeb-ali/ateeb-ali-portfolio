# Syed Ateeb Ali — Portfolio

Personal portfolio site for me. Covers experience, projects, security practice, CTF profiles, speaking, skills, and certifications.

**Live site:** https://ateebali.netlify.app/

## Tech stack

Plain HTML/CSS/JS — no framework, no build step.

## Project structure

```
.
├── index.html      # Page markup
├── styles.css      # Styling
├── data.js         # All content — experience, projects, skills, certs, etc.
├── script.js       # Renders data.js into the page + interactivity
└── assets/
    └── profile.png # Profile photo
```

## Running locally

Just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```
